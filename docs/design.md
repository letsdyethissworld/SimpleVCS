# Дизайн Simple VCS

## Компоненты

- **Объекты**: Блобы, деревья, коммиты
- **Рефы**: Указатели на коммиты
- **Индекс**: Область подготовленных файлов

## Структура данных

.simple_vcs/
├── objects/ # Хранилище объектов
├── refs/ # Ссылки на коммиты
├── HEAD # Текущая ветка
└── index # Индекс файлов
